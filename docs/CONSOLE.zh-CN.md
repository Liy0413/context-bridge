# 中文终端控制台 · 0.2.0

在克隆的 Context Bridge 仓库目录打开 PowerShell：

```powershell
.\context-bridge.cmd
```

CMD 使用 `context-bridge.cmd`。完整主副设备顺序见 [安装与连接](INSTALL.md)。

## 菜单

```text
 [1] 首次初始化（只运行一次）
 [2] 启动本地服务
 [3] 停止本地服务
 [4] 启动 Cloudflare 临时隧道
 [5] 停止 Cloudflare 临时隧道
 [6] 复制 owner 密钥并显示连接参数
 [7] owner 工作区管理（创建工作区/邀请码）
 [8] 使用公网地址和邀请码加入
 [9] 局域网自动发现并加入
[10] 启用主设备局域网防火墙规则
[11] 安装 Agent Skills
[12] 将项目连接到插件半自动同步
[13] 查看说明和日志路径
[14] 安装/更新本机 Context Bridge 插件
 [0] 退出
```

`[1]`、`[2]`、`[3]`、`[4]`、`[5]`、`[10]` 由主设备操作。副设备通过 `[8]` 或 `[9]` 加入已经运行的服务。

## 工作区和邀请

`[7]` 首先选择本机、公网隧道或手动输入的 MCP 地址，然后提供：

```text
[1] 查看当前身份
[2] 列出工作区
[3] 创建工作区
[4] 创建一次性邀请码
[5] 发布文字检查点（不含文件）
[6] 更换 MCP 地址
[0] 返回主菜单
```

邀请码可选择 `editor`（读写检查点）或 `viewer`（只读），有效期为 1–168 小时。每个码只可成功加入一次。菜单发布只提供标题、摘要和下一步；项目文件交接由代理执行发布 Skill。

## 插件安装和项目连接

每台设备先运行 `[14]`。控制台为 Codex 注册仓库中的 marketplace 并安装或刷新插件；同时为 Cursor 创建本地插件包。安装包只复制公开分发文件。

随后运行 `[12]`：

1. 输入实际工作项目完整路径。
2. 主机选择服务地址并使用 owner 身份；副机自动读取仓库中的个人连接文件。
3. 输入工作区名称，默认“测试工作区”。
4. 重启代理，启用 Context Bridge，审核插件 Hook，在工作项目中新建对话。

每个工作项目只建立本机连接标记，不复制 Hook。项目标记记录工作区、服务地址和凭据文件路径；移动源码目录或凭据文件后应再次运行 `[12]`。

`[11]` 用于单独安装四个 Agent Skills，支持的代理及目录见 [技能说明](SKILLS.md)。只装技能不会获得半自动触发能力。

## 同步行为

插件在会话启动时查询最新检查点，向代理提供摘要及文件哈希比较。代理先展示匹配、缺失、不同文件，再等待用户确认应用；本地修改需要合并或保留。成功应用后，代理按 Hook 给出的命令记录检查点 ID。

文本项目文件发生变化时，代理在结束响应前询问是否发布。同一批修改只询问一次；用户同意后执行发布 Skill。直接关闭应用不会保证出现结束询问。检查范围与文件限制见 [README](../README.md#插件内置半自动同步)。

Codex 使用 `SessionStart`/`Stop`，Cursor 使用 `sessionStart`/`stop`。Cursor 新建对话触发启动检查；Codex 还支持恢复和压缩续接。Hook 故障会放行，在宿主的 Hook 输出中查看原因。

## 日常启动与日志

主机运行 `[2]`，需要公网临时测试时再运行 `[4]`。已加入设备无需重新邀请码。

控制台启动的服务和隧道在关闭菜单后继续运行。状态和日志在 `.tools/context-bridge-console/`。停止操作核对 PID 和启动时间；其他终端启动的服务需到原终端停止。

## 故障处理

- **终端找不到 node/codex**：安装对应程序后重开终端，确认命令可执行。
- **局域网发现不到**：主机启动服务并启用 LAN 发现，网络设为专用，通过 `[10]` 开放 TCP 8787、UDP 8788；检查路由器客户端隔离。
- **邀请码无效**：确认同一服务，重新创建未使用且未过期的码。
- **已存在 connection.local.json**：已加入的设备通常无需重复加入，先验证现有身份。
- **MCP 401**：核对当前服务和个人 Bearer 凭据，邀请码不能代替 API Key。
- **Hook 未出现**：运行 `[14]` 后重启代理，在插件设置确认 Context Bridge 启用并完成审核；检查 Hook 输出，不要向工作项目手动添加 Hook。
- **没有新检查点提示**：核对 `[12]` 选择的项目、工作区和服务，确认发布成功且本机尚未标记已应用，然后新建对话。
- **临时地址失效**：主机获取当前隧道 URL，更新代理 MCP 设置、连接文件及 `[12]` 项目标记。
- **服务端日志错误**：用 `[13]` 查看日志路径，并参照 [部署说明](DEPLOYMENT.md)。

凭据、连接文件、服务数据和状态文件均须保持在 Git 忽略范围内。LAN HTTP 仅用于可信专用网络。
